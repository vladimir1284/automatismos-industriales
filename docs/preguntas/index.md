# Banco de preguntas

Preguntas en formato [GIFT](https://docs.moodle.org/en/GIFT_format) (Moodle), organizadas por categoría bajo un único árbol raíz `AIA`, alineado con los temas del programa de la asignatura (ver [Conferencia 1](../notas-clase/conf-01.md)).

| Archivo | Categoría Moodle |
|---|---|
| [`actuadores.gift`](actuadores.gift) | `AIA / Tema I / Actuadores` |
| [`sensores.gift`](sensores.gift) | `AIA / Tema I / Sensores` |
| [`rele_y_contactores.gift`](rele_y_contactores.gift) | `AIA / Tema II / Relés y Contactores` |

Pendiente de banco de preguntas: Tema III (autómatas programables) y Tema IV (sistemas eléctricos de potencia).

## Importar a Moodle

*Administración del curso → Banco de preguntas → Importar* → formato GIFT → seleccionar el archivo. Las líneas `$CATEGORY` del archivo crean/seleccionan automáticamente la categoría de destino dentro del árbol del curso.
